# Tooting Tub

Four animals share one inflatable tub on a spiky canal. The only way to move is to fart.

**Play:** https://kmohit31.github.io/tooting-tub/

- **Solo / same device:** arrow keys or WASD (hold to keep tooting), Q / Z / M / P for four players on one keyboard, or tap the animal buttons.
- **Online with friends:** choose "Play online with friends", create a room and share the 4-letter code or invite link. Each friend picks an animal on their own device and you all steer the same tub.

The whole game is the single file `index.html`. Online rooms connect browsers directly using PeerJS.
